# change-review

> Focused review of diffs for concrete bugs and regressions.

## Install in Codex

Add this repository as a plugin marketplace, then install the released plugin:

```powershell
codex plugin marketplace add GhosTnever-lkm/change-review
codex plugin add change-review --marketplace change-review
```

Codex may ask you to restart or reload plugins before the skill becomes available. The source for this release is tagged `v1.0.1`.

## Use it

Start a Codex task that matches the skill's purpose. The plugin instructions live in `skills/` and are included in the marketplace source for inspection.

## Scope

This is a focused Codex skill. It has no external service, background process, or credential requirement. See the skill file for its workflow and limits.
